Report on a stored round, asking no provider: $ARGUMENTS

Use `askround_report`, with `round` set to the arguments when they name one, and without
it for the latest round. Report where the product is named, the rivals, the claims and
what the round cost, and say when it was asked: an old round is not today's answer.
